## Reviewer commands

From the Asset checkout, with a sibling App checkout that contains the recorded App baseline:

```sh
python -m pip install Pillow==12.3.0 pytest
python -m pytest tests
python scripts/migration_audit.py 4d2efecf86312788d36d83dc557907ff0dece795 ../app b6faeb8304791225a2d99742a7024ed0011f2b1e
```

The migration manifest accounts for every original art path. Promotion only consumes reviewed files
under Transfer. The workflow checks duplicate paths in open PRs and verifies the staged changes
against the manifest before publishing. If publication fails, it closes the run's open PRs and
deletes the run's branches, reporting any cleanup failure in the workflow log.

The owner must enable GitHub Actions to create pull requests in Asset and add an Asset Actions secret
named `APP_PROMOTION_TOKEN`. Restrict the token to App with Contents and Pull requests read/write.
Asset uses its workflow `GITHUB_TOKEN` with Contents and Pull requests write permissions.
No promotion PR is merged automatically.
